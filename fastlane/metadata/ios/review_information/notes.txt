Basic Voice Notes has no account or sign-in, and the developer runs no server.

The quickest way to test needs no API key and works offline:
1. Tap the gear icon (top right) to open Settings, then tap Provider under Transcribe.
2. Choose "On this device", then tap Download next to the Base model (about 160 MB; Wi-Fi recommended).
3. Go back to Notes, tap Record, say a sentence, then tap stop. (Or tap the import icon and choose an audio file.)
4. A few seconds later the note shows a transcript, with an English translation if "Translate to English" is on in Settings.

Titles, summaries, templates and online transcription use the user's own API key from Sarvam, OpenAI, Google Gemini or OpenRouter, added under Settings > API keys. The app sends audio or text directly from the device to that provider. A free Google Gemini key takes about two minutes to create: https://amitrke.github.io/voice-notes/api-keys/

Without a key, the app still opens normally, and a banner explains what is needed.

Permissions: the app asks only for microphone access, when recording. It also has an optional "Clinical work" setting, off by default, that drafts a clinical note from a transcript. The app is not a medical device.
